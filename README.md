# Binoy Daniel Portfolio

Static HTML/CSS portfolio prepared for GitHub Pages.

## File structure

- `index.html` — homepage
- `style.css` — shared styling
- `projects/physioqc.html`
- `projects/wearable-pipeline.html`
- `projects/cardiac-mapping.html`
- `projects/eeg-motor-imagery.html`
- `assets/` — add screenshots, diagrams, PDFs, and other media here

## Deploy

1. Copy these files into the root of your `bdaniel917.github.io` repository.
2. Commit and push to the repository's default branch.
3. GitHub Pages should publish the site automatically.
4. Replace each dashed placeholder with an `<img>` or `<video>` element.

Example image:

```html
<figure>
  <img src="../assets/physioqc-dashboard.png"
       alt="PhysioQC dashboard showing signal-quality events">
  <figcaption>Signal quality events detected in a simulated EEG stream.</figcaption>
</figure>
```

## Important

The wearable pipeline page is deliberately written as a generalized case study.
Do not add proprietary data, internal screenshots, confidential architecture, or
unverified performance claims.
