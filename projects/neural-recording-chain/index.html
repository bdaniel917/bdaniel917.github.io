INDEPENDENT ENGINEERING STUDY · 01

Neural Signal Chain Simulation

I wanted to make the path from electrode to digital filter concrete enough to perturb. The aim was not to imitate a particular device; it was to see which parts of a simple measurement model matter, and where the model stops being trustworthy.

PYTHON / NUMPY200 TRIALS · SEED 7INDEPENDENT STUDY · OCTOBER 2026

Why model the whole path?

An algorithm can only work with the samples it receives. Before they become samples, a neural signal has already interacted with a source impedance, input capacitance, analog bandwidth, gain, and converter range. A digital filter may clean up some noise, but it cannot reconstruct clipped samples or undo a bandwidth limit without additional assumptions.

I built this as a small end-to-end experiment: start with a deterministic synthetic waveform, vary a few acquisition assumptions, then inspect output SNR and clipping together. The point is to make tradeoffs visible before deciding that the next improvement belongs in software.

What the model actually computes

The source combines two sinusoids with short, biphasic transients. It is deterministic so that changes in the acquisition parameters can be compared against the same underlying waveform.

The interface is a first-order source-resistance/input-capacitance divider:

Hₑ(jω) = 1 / (1 + jωRₛCᵢₙ)

This captures one useful consequence of finite input impedance: the signal transfer changes with frequency. It is intentionally much simpler than an electrochemical electrode model, which can include complex, frequency-dependent impedance and polarization effects.

For the noise terms, I used a bandwidth-based Johnson noise estimate for the source resistance, plus independently sampled amplifier voltage and current noise. The current-noise contribution is converted to voltage through the source resistance. These terms then pass through a one-pole analog low-pass filter and gain stage.

Modeling caveat. The noise RMS is estimated from a bandwidth, then represented as a per-sample random sequence. It is not a frequency-domain noise-density simulation. The resulting noise behavior is useful for relative experiments within this model, not as a validated input-referred noise budget.

The ADC clips at its configured full-scale range, then quantizes to a signed code width. I convert the codes back to input-referred units before a symmetric nine-tap FIR. The FIR coefficients are quantized to Q12 integers; I adjust the center coefficient after rounding so their integer sum remains exactly unity.

coeff_q = round(coeff × 2¹² / sum(coeff))
coeff_q[center] += 2¹² − sum(coeff_q)

accumulator = convolution(input_codes, coeff_q)
output_codes = rounded_shift(accumulator, 12)

The accumulation uses a wide integer type. I do not yet simulate a narrower hardware accumulator or prove overflow bounds; that is a separate fixed-point design question.

What changed across the sweep

For each of 200 seeded trials, I drew gain, source resistance, input capacitance, amplifier noise, analog cutoff, ADC range, and bit depth from explicit ranges. I compared the quantized-and-filtered output with a clean reference passed through the same R–C and analog bandwidth model.

A useful next step would be a designed experiment: hold the noise seed fixed, sweep gain against ADC range on a grid, and plot a two-dimensional clipping/SNR surface.

What the reference lets me measure

The SNR here is not measured against the raw synthetic source. The reference travels through the same simplified electrode response, analog low-pass, and digital FIR as the noisy run. That choice removes those shared transformations from the error comparison; the remaining difference reflects the modeled noise and conversion path, including clipping.

That makes the comparison useful for asking how the converter path changes an already bandwidth-limited signal. It also narrows the claim: this SNR does not measure how faithfully the entire chain reproduces an electrode voltage, and it does not tell me whether the synthetic waveform resembles a particular neural recording.

How I read the plot: use SNR and clipping together. A high SNR can hide a small but consequential set of saturated transients; a low clipping rate alone can come from a range so wide that the signal uses few ADC codes. The operating point is a tradeoff constrained by the amplitude distribution.

What I learned from building it

01

Gain has two jobs.

It can use more of the converter's code range and reduce input-referred quantization step size. It can also make a large transient hit full scale. Choosing gain without looking at the expected amplitude distribution is incomplete.

02

Noise should be budgeted before filtering.

A filter can change in-band noise, but it cannot restore signal lost to the interface response, and it should not be treated as a substitute for understanding the analog path.

03

A model is useful when its omissions are legible.

This version makes a few assumptions easy to test. Its value is not that it predicts a real implant; it gives me a place to ask better questions before component specifications or bench measurements are available.

Limits and next experiments

  • No device-specific electrode, amplifier, or converter specifications.
  • R–C interface is a single-pole approximation, not an electrochemical model.
  • Noise power is approximate; colored noise and spectral density are not modeled.
  • No anti-alias filter, common-mode behavior, interference coupling, or amplifier saturation.
  • ADC is an ideal uniform quantizer; the FIR accumulator does not emulate a specific hardware word width.

A next version should make the noise model frequency-aware, add an anti-alias stage, and sweep gain and converter range jointly with fixed random seeds. I would plot the joint SNR/clipping surface and look for regions that satisfy both constraints, rather than optimize one metric in isolation. If real component data becomes available, the parameters should come from datasheets and bench characterization rather than generic ranges.
