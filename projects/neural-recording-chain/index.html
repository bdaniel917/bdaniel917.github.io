How to read these measurements

SNR compares the output with the clean signal through the same linear filters. It measures added error, while clean-path attenuation is reported separately. Feature bias compares 70–250 Hz power against the original gain-scaled neural input. A small net bias can conceal cancellation between attenuation and added interference. PSD uses a normalized one-sided Hann periodogram in FS²/Hz. Display bins average adjacent PSD bins; the metrics use the original data.
