ACADEMIC PROJECT / EEG

EEG Motor Imagery Classification

I used MNE to work through EEG epochs and built a Common Spatial Patterns + Linear Discriminant Analysis baseline on BCI Competition IV, Dataset 2a. I like this kind of baseline because each step has a signal-processing interpretation.

MNECOMMON SPATIAL PATTERNSLINEAR DISCRIMINANT ANALYSIS

Why start with CSP + LDA?

Motor imagery changes the spatial distribution of band-limited EEG power. Common Spatial Patterns finds projections that make the variance contrast between classes more visible. A classifier can then work on a compact feature representation rather than on every sensor sample independently.

In the two-class case, the spatial filters are related to the generalized eigenvectors of the class covariance matrices. A useful way to think about the objective is to find a projection whose variance is large for one class relative to the other:

maximize   wᵀΣ₁w / wᵀ(Σ₁ + Σ₂)w

With multiple classes, the exact strategy matters: one-vs-rest, pairwise decomposition, or a multiclass method can produce different features. That implementation detail belongs in the analysis record, not just in the name “CSP.”

The benchmark is small in one important way

BCI Competition IV Dataset 2a contains four cued motor-imagery classes, 22 EEG channels, 3 EOG channels, and recordings from 9 participants at 250 Hz. That is enough structure to compare a classical pipeline, but nine people are not a broad sample of the population a deployed BCI would encounter. I use the benchmark to study a method and its evaluation boundary, not to claim clinical readiness. Dataset details.

The evaluation boundary matters

CSP is a learned transform. Its covariance estimates must be fit using training data only. If the transform is fit once using all trials before cross-validation, information from the held-out trials can leak into the features even though the final classifier never sees their labels.

For a careful evaluation, I would keep filtering and epoch construction consistent, fit CSP inside each training fold, and report the split unit and class-wise results. When trials from a participant share session structure or drift, the split should reflect the question being asked: new trials from a known session is different from generalization to a new session or person.

What belongs inside the fold

CSP estimates spatial filters from class-labeled covariance structure. If I estimate those filters once using every epoch and then cross-validate only LDA, the held-out epochs have already influenced the representation. The classifier has not seen their labels, but the evaluation is still contaminated. The same question applies to any data-fitted scaling, feature selection, or threshold choice.

My rule is to put every learned transformation inside the cross-validation pipeline, then fit it on each training fold only. The fold should match the claim: a random trial split asks about held-out trials under a similar session mixture; a held-out session asks about session transfer; a held-out participant asks a harder question about generalization to a new person. Those are different results, so they should not share one unlabeled “accuracy.” MNE CSP reference.

What I take from the baseline

A classical model is useful here as a diagnostic instrument. If performance changes sharply with frequency band, epoch window, or spatial projection, that tells me where the signal is carrying class information and where the analysis is sensitive. It also gives me a reference before introducing a higher-capacity model.

I’m not reporting an accuracy number on this page because the reproducible notebook, exact split strategy, and run outputs are not bundled here. The next useful step is to publish that code and include balanced accuracy, per-class recall and confusion, subject-level variation, fold-level uncertainty, and a clear statement of what population the split is meant to generalize to.
